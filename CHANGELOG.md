# Changelog

Release notes for mod_accredible. The section matching a release tag is
submitted as that version's changelog on the Moodle Marketplace.

Add a `## vX.Y.Z` section as part of the version bump on the release branch,
before the tag is created. Marketplace versions cannot be edited after they
are submitted, so whatever is written here is permanent for that release.
